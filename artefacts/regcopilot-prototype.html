Ask a regulatory question

Natural language. No search syntax. Evidence-backed answers with verifiable citations from PRA Basel 3.1 sources.

How to use RegCopilot

  • Type your question as you would ask a colleague — e.g. “How are retail exposures treated under the standardised approach?”
  • Set an “as of” date if you need the view at a point in time — default is today. Source statuses (Final, Future-Effective, Superseded, Proposed, Explanatory) are shown relative to that date.
  • Answers are a synthesis of cited sources — never an applicable requirement. Conflicting sources are shown side-by-side; RegCopilot never picks one for you.
  • Every citation expands to the surrounding passage so you can verify without opening the source document.
