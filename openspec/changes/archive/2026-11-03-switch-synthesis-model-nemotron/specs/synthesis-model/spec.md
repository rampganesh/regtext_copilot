# Spec Delta

## Purpose

Ensures the configured local chat model used for answer synthesis is invoked with thinking disabled,
so responses contain only the final answer text.

## ADDED Requirements

### Requirement: Thinking disabled for synthesis

The system SHALL invoke thinking-mode chat models with thinking disabled, so the returned answer
contains only the final answer text and no reasoning-channel content.

#### Scenario: Only final answer is returned

- **WHEN** an answer is generated by a thinking-mode chat model
- **THEN** the response used for synthesis contains the final answer text and no reasoning (thinking)
  content

#### Scenario: Generation settings unchanged

- **WHEN** an answer is generated
- **THEN** the call uses temperature 0 and does not stream to the analyst
